# Java — Practice Projects and Applications

A compact repository for Java learning, practice, and production mini-projects — demonstrating OOP design patterns, Swing GUI, Spring Boot, security, and unit testing.

## Contents

- **[atm-interface/](file:///f:/works/Java/atm-interface)** — NextGen ATM system with modern dark Swing GUI, CLI fallback, SHA-256 PIN security, cash vault dispenser inventory, and transaction mini-statements.
- **[ai-riddle-game/](file:///f:/works/Java/ai-riddle-game)** — AI Riddle Arena with Spring Boot 3, Spring Security (JWT), JPA/Hibernate, fuzzy answer engine, and dark gaming UI.
- **[calculator/](file:///f:/works/Java/calculator)** — Swing-based smart calculator application.
- **[tictactoe/](file:///f:/works/Java/tictactoe)** — Two-player Tic Tac Toe built with Swing.

## How to use

1. Browse the folders for individual projects.
2. Each project contains a dedicated `README.md` with run instructions and examples.
