# Java — Practice Projects and Examples

A compact repository for Java learning and practice — small projects, example programs, and code snippets that demonstrate core Java concepts (OOP, collections, concurrency, file I/O). Use this repo as a study reference or a playground for solving beginner-to-intermediate Java exercises.

Contents

- calculator/ — Swing-based smart calculator application
- tictactoe/ — Two-player Tic Tac Toe built with Swing

How to use

1. Browse the folders for individual projects.
2. Each project contains a short README with run instructions and examples.
3. To run a project, compile the .java files (javac) and run the Main class as documented in the project README.
